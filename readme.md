# MO OS — Developer Edition

A calm, editorial operating system for software developers.

![MO OS Preview](image%20(22).png)

**Live:** [mo-os-alpha.vercel.app](https://mo-os-alpha.vercel.app/)
**GitHub:** [github.com/muhammad-bin-junaid/mo-os](https://github.com/muhammad-bin-junaid/mo-os)

## Features

- Window manager 
- Files & Folders 
- Terminal with commands 
- Notes with auto-save
- Projects manager (create, edit, delete)
- Browser with search, AI assistant, Google integration
- Music player with step sequencer builder 
- Maps (Google Maps embed)
- Calculator
- Calendar
- Code editor (VS Code-like with tabs, line numbers, file explorer)
- Settings with wallpaper picker
